# Virus Diffusion

This project provides the computational framework for a report investigating the use of shields to slow the diffusion of virus-bearing particles in a room. By disrupting particle spread, shields can help reduce the risk of infection, making the material’s diffusivity a key factor in their effectiveness. The model represents particle transport using a one-dimensional diffusion equation, with an exact analytical solution applied to capture pre-shield diffusion. A numerical approach then simulates particle concentrations over time to assess shield performance. The objective is to identify an optimal diffusion coefficient that reduces particle levels by at least half within 2 hours and 40 minutes. 

The code was developed in Python using Jupyter Notebook.
